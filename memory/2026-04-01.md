## Key Learnings

1. **Never import secret keys in client code** — Always separate lib files by execution context
2. **Nginx conf.d directives** — Can't use main-context directives (user, worker_processes) in included files
3. **Docker network hostnames** — Use container names for inter-container communication (e.g., `laverdi-portal:3000`)
4. **Certificate paths** — Match the actual mount points in docker-compose volumes
5. **Browser cache** — Hard refresh necessary after deploying new JS bundles
