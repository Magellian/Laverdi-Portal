## Key Learnings

1. **SCP file corruption** — Text-based files sometimes arrive corrupted through SCP. Direct Node file writes work better.
2. **PM2 auto-restart** — Portal was being managed by PM2, causing infinite restart loops. Deleted from PM2.
3. **Socket TIME_WAIT** — Even after `kill -9`, sockets take time to release. Switching ports works.
4. **Cloud-init reliability** — Scripts in cloud-init are fragile. Need error handling and logging.
