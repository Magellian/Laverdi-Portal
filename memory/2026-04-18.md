## Architecture Decisions

**Multi-Agent + Shared Credits:**
- Each user can have multiple agents (tier-limited)
- ALL agents share monthly credit pool
- Can't exceed tier limit even with multiple agents
- Example: Starter (1000 credits) shared by 3 agents

**Credit System:**
- Token-based pricing per model
- Monthly reset automatic on 1st
- Real-time enforcement (reject calls over limit)
- Per-agent tracking in usage_logs

**Communication Integrations:**
- Webhook-based (not polling)
- Signature verification per platform
- All messages logged for audit trail
- Messages count toward tier credits
