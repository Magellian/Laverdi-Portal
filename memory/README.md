# Memory Journal System

This folder holds Crawford's day-by-day working memory.

## Files

- `YYYY-MM-DD.md` — Daily journal for important discussions, decisions, progress, and follow-ups
- `heartbeat-state.json` — Lightweight state for periodic checks, if used

## Daily journal rules

- One file per day
- Append important context throughout the day
- Do not try to store full transcripts
- Prefer concise bullets and short sections
- Capture things future sessions should know

## Suggested structure

```md
# 2026-03-19

## Discussions
- Important conversation or context

## Decisions
- Decision made and why

## Progress
- Systems changed, files updated, work completed

## Follow-ups
- Open loops, next steps, reminders
```

## Purpose

Daily files are raw but useful continuity.
`MEMORY.md` is the distilled long-term version.
