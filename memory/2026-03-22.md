# 2026-03-22

## Issues
- Anthropic API ran out of credits, causing Crawford to become unresponsive.
- After credits were refunded/added, the gateway stayed in a hang state and wouldn't update status or respond.
- Required manual intervention (likely a gateway restart) to recover.
- Multiple pings from ~12:34 PM through ~2:46 PM went unanswered or delayed during the outage.

## Takeaway
- When an API provider returns auth/billing errors, OpenClaw gateway may cache the failure state and not auto-recover when the provider comes back online. A `openclaw gateway restart` may be needed.
