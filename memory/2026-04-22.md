### Key Lessons Learned
1. `docker restart` does NOT apply code changes - always `docker build` then run new container
2. OpenClaw has 3 security layers: origin check, HTTPS secure context, device pairing
3. `getServerSideProps` cannot return `revalidate` key - causes 500 error at runtime
4. OpenClaw config invalid keys crash gateway entirely on startup
5. nginx `server_name _` catch-all blocks named vhosts - always use explicit server_name
