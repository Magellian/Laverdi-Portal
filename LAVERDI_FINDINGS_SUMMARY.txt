ISSUE #1: HOSTNAME RESOLUTION FAILURE
  ────────────────────────────────────────────────────────────────────────
  Status: CRITICAL (breaks Telegram pairing)
  
  Problem:
    Portal tries to call: http://laverdi-command-center:8000
    But hostname "laverdi-command-center" doesn't resolve
    
  Root Cause:
    • No DNS record exists
    • No /etc/hosts entry on server
    • Command Center only listens on localhost:8000
    
  Evidence:
    $ nslookup laverdi-command-center 8.8.8.8
    ** server can't find laverdi-command-center: NXDOMAIN
    
    $ cat /etc/hosts
    127.0.0.1 localhost
    127.0.1.1 laverdi-portal-seattle
    (no laverdi-command-center entry)
    
    $ curl http://localhost:8000/health
    200 OK - {"status": "healthy"}
    
    $ curl http://laverdi-command-center:8000/health
    ERROR: Name resolution failed
    
  Fix: 2 minutes
    Option A: echo "127.0.0.1 laverdi-command-center" >> /etc/hosts
    Option B: Change VPS_API_URL=http://127.0.0.1:8000 in .env.local

  Impact: Portal cannot reach Command Center for ANY API calls
