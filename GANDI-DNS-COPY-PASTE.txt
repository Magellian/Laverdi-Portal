HOW TO ADD THESE RECORDS:

1. Go to: https://www.gandi.net
2. Log in
3. Click: Domains
4. Click: laverdi.tech
5. Click: DNS Records (or "Manage Zone")
6. Click: "Add a DNS Record" (or "Add Record")
7. For EACH record below:
   - Copy Name → Paste into "Name" field
   - Copy Type → Select from dropdown
   - Copy Value → Paste into "Value" field
   - Click "Save"
8. Repeat for all 3 records
9. Done! DNS will propagate in 5-10 minutes
