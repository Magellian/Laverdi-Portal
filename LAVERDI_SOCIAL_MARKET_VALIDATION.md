## 4. Platform API Status (2026)

### YouTube Data API
- **Status:** ✅ Official, stable
- **Upload:** Yes (via API)
- **Scheduling:** Yes (via publishAt parameter)
- **Limitations:** Requires verification, 100 uploads/day quota
- **Difficulty:** Medium (OAuth2 required)

### TikTok Business API
- **Status:** ⏳ Official but limited
- **Upload:** Yes (recent addition 2025)
- **Scheduling:** Limited (creators only, instant publish mainly)
- **Limitations:** Approval process, limited access
- **Difficulty:** Hard (requires TikTok Business approval)
- **Workaround:** Browser automation (Selenium) still viable

### Instagram Graph API
- **Status:** ✅ Official, mature
- **Upload:** Yes (media containers)
- **Scheduling:** Yes (schedule_publish_time)
- **Limitations:** Requires Business Account, approval process
- **Difficulty:** Medium

### X/Twitter API
- **Status:** ✅ Official (API v2)
- **Upload:** Yes (media upload)
- **Scheduling:** No (must publish immediately, but can use job queues)
- **Limitations:** Twitter API v2 access required ($100/mo tier minimum)
- **Difficulty:** Easy-Medium

### Facebook Graph API
- **Status:** ✅ Official, mature
- **Upload:** Yes
- **Scheduling:** Yes (scheduled_publish_time)
- **Limitations:** Requires Page admin access
- **Difficulty:** Medium

**Verdict:** All platforms have APIs. TikTok is the hardest but doable.
